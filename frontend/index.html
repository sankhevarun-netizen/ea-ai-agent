ARB
Architecture Review Board
Governance Agent

Evaluates architecture proposals and technology decisions against governance standards. Returns APPROVE / REJECT / CONDITIONAL verdicts with compliance scores and risk flags.

EA Relevance

Critical for enforcing architectural standards, regulatory compliance and preventing ungoverned technology proliferation across the enterprise.

Rationalization Agent
Portfolio Rationalisation

Scores every application across 7 dimensions and classifies it as Tolerate · Invest · Migrate · Eliminate with a 6R action (Retain, Rehost, Replatform, Refactor, Replace, Retire).

EA Relevance

Foundation of EA rationalization — drives cost reduction, eliminates technical debt and aligns portfolio investment with strategic business outcomes.

M
Mapping Agent
Dependency Analysis

Analyses upstream/downstream dependencies, integration complexity and migration risk for flagged applications. Produces coupling scores and change impact assessments.

EA Relevance

Essential for safe decommissioning and migration planning — prevents service disruption by identifying hidden dependencies before retirement or replacement decisions.

M
Maturity Agent
Capability Assessment

Scores EA practice maturity across 8 dimensions on a 1–5 scale (Vision, Governance, Architecture Development, Portfolio, Data, Technology, Integration, Tools). Produces improvement priorities.

EA Relevance

Benchmarks where the EA function stands today across COBIT/TOGAF dimensions — enables targeted capability investment and tracks year-on-year improvement.
